# Batteries Charging

## Compute

For the AZ-Delivery Raspberry Pi PowerPack v2.0

1. Connect a Micro USB cable to the Charge connection port on the PowerPack board.
2. Observe the LED indicator on the PowerPack board. 
3. The Charge (CHG) LED will be blinking red??? when charging 
4. The Charge (CHG) be static red/off when charging is complete.
